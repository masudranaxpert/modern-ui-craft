# Galary (Inbox / Staging) 📥

Drop your raw screenshots or design references here.

When you drop images here and ask the assistant to organize them, it will:
1. Identify the screen type (web dashboard, landing, settings, mobile finance, fitness, etc.)
2. Give the file a semantic slug name (e.g. `fintech-card-stats.jpg`)
3. Move it to the appropriate subfolder inside `gallery/web/` or `gallery/mobile/`
4. Update the category's `README.md` table and notes with palette and layout info
